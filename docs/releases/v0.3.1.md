# Android ART Optimizer 0.3.1

This update builds on the 0.3.0 preview with automatic connection setup, cleaner app lists, and interface refinements.

## What changed since 0.3.0-preview

- **Automatic Wireless Debugging setup**:
  You no longer need to toggle Wireless Debugging manually in Developer Options every time you use the app. Once granted `WRITE_SECURE_SETTINGS` on initial connection, the app turns it on automatically when opened.

- **Disconnect & turn-off action**:
  A new button on the Device screen lets you disconnect and shut off Wireless Debugging system-wide in one tap.

- **Cleaner app discovery**:
  The discovery list now shows only the third-party apps you actually installed. Updated system services (such as WebView and Google Play Services) and ART Optimizer itself are hidden so you only optimize your personal apps.

- **Remove all configured apps**:
  Added a **Remove all** button on the Configured page to reset your selected apps in one tap.

- **Background status progress**:
  Status checks now stream in the background with an active counter (`Checking status X/Y`), keeping compilation buttons locked until checking finishes to avoid redundant runs.

- **Material You dynamic theming**:
  The interface adapts to your device wallpaper palette on Android 12+ while retaining the pitch-black AMOLED mode.

## Installation

Download **android-art-optimizer-v0.3.1-debug.apk** below and install it on Android 11+. You can install this build directly over the 0.3.0 preview.
